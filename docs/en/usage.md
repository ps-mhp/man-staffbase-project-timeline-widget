# Step by step

## Create the plan

1. Put the widget **Project Plan** on the page, preferably in a
   wide column: A timeline needs space in the width. In a
   narrow column, it remains operable, but shows less at a time. 
2. Open the widget's settings. The plan editor opens from
   himself. 
3. A new plan starts with a "Level 1" layer. Would you rather
   a finished template, follow the section "Using the
   Sample Plan". 
4. At the top of the plan editor, under **Heading**, optionally add a title
   for the plan. It stands above the plan and gives the Excel file its
   Names. 
5. Create the layers in the **Layers** tab — see "Maintain layers". 
6. In the **Categories** tab, create the categories with their colors — 
   see "Maintaining categories". 
7. In the **Entries** tab, set the milestones, time periods, and deadlines
   — see the following sections. 
8. Click on **Apply**. 
9. In the dialog, check the buttons **Show Today Line** and
   **Offer Excel export**; both are pre-enabled. 
10. Save the page and preview the result. 

## Start with the sample plan

1. Open the settings of a widget whose plan is still empty. 
2. In the Plan Editor, click **Start with Sample Plan**. The Editor
   is filled with the heading "Sales Truck Launch", three levels, seven
   Categories and entries based on the model of the Sales Truck Launch Plan. 
3. Customize the headline, layers, categories, and entries to fit your project
   or delete what you don't need. 
4. Click on **Apply** and save the page. 

## Maintain layers

1. In the Plan Editor, open the **Layers** tab. 
2. To create a layer, click on **New Layer** and enter
   Enter her name. 
3. To rename a layer, change its name directly in the list. 
   Next to each name is how many entries the layer contains. 
4. To change the order, move the layer with the arrows
   up or down. The order here is the order on the
   page and in the Excel export. 
5. To delete a layer, click **Delete**. Does it still contain
   entries, the editor asks if they are moved to another layer
   — which you select under **Target Level** — or whether they are also deleted
   . Confirm with **Delete** or break with **Cancel** 
   . 

## Maintain categories

1. In the plan editor, open the **Categories** tab. 
2. To create a category, click on **New category** and
   enter their name. 
3. Under **Color**, select one of the twelve color swatches or enter
   **Hex value** enter its own color, for example '#E40045'. 
4. To change the order of the legend, move the category
   with the arrows pointing up or down. 
5. To delete a category, click **Delete**. Your entries
   are retained and become "without category" (grey); the query mentions, 
   how many entries this affects. 

## Create a milestone

1. In the plan editor, open the **Entries** tab. 
2. Under **Add**, click **Milestone**. The new
   Entry is called "New Milestone", is in the middle of the preview and in
   of the first level; on the right his form appears. 
3. Enter the **title** and optionally a **description**. The
   Description appears in the details, line breaks are retained. 
4. Select the **Level** and the **Category** — or "Without Category". 
5. Enter the **date**. 
6. Under **Symbol**, select Diamond, Triangle, Square, or Circle. 
7. Set **Tentative** if the date is not yet fixed. 
8. Click on **Apply** once all entries are ready. 

## Create a time period

1. In the **Entries** tab, under **Add**, click
   **Period**. The new entry will be called "New Period". 
2. Enter **Title**, optional **Description**, **Level** and
   **Category**. 
3. Enter **Start** and **End**. Both days belong to the period. 
4. Put **arrow at end** if the period is beyond the end
   continues. 
5. Set **Tentative** if the start or end is not yet fixed. 

A milestone can be changed to a period of time at any time under **Art**
and vice versa. 

## Create a deadline

1. In the **Entries** tab, under **Add**, click
   **Deadline**. 
2. Enter **Title**, optional **Description**, **Category** and
   **Date**. There is no level here: A cut-off date applies to the
   whole plan and runs through all levels. 

If a milestone or period under **Art** becomes the cut-off date, it does not apply.
level. 

## Combine entries into a series

1. In the **Entries** tab, select the first entry in the series. 
2. Enter a name under **Series**, for example "TG Assist MY26". 
3. Select the next entry of the same layer and enter under
   **Series** is exactly the same name. The field suggests the series that
   already exists in this level. 
4. Repeat step 3 for all entries in the series. 

Series only apply within one level. Look for identical
Spelling: "TG Assist MY26" and "TG-Assist MY26" are two different
series. 

## Set a dependency

1. In the **Entries** tab, select the entry that has been created by another
   (the successor). 
2. Under **Depends on**, find and select the predecessor. Multiple
   Predecessors are possible. 
3. On the page, a dotted line with an arrow now connects the
   Predecessor with successor. 

Dependencies only exist between milestones and time periods, not for
deadlines. If an entry is deleted, it will also disappear from all
Dependencies. 

## Duplicate and delete entries

1. Select the entry in the **Entries** tab. 
2. **Duplicate** creates a copy, which you then adjust. 
3. **Delete** removes the entry and all dependencies that are on it
   show. 

## Set the home view

Without a start view, the widget shows the whole plan when loading. Should it
instead show a certain excerpt, for example the next two years: 

1. Zoom and pan the **Preview** in the Plan Editor until the
   can be seen in the desired section. 
2. Click on **This section as home view**. Saving
   To the month. 
3. To show the whole plan again, click on **Start view
   Remove**. 
4. **Apply**, save, check in the preview of the page. 

Readers can zoom in at any time from the home view or
**Show all** see the full plan. 

## Change afterwards

1. Open the widget's settings again. The Plan Editor will display the
   saved plan. 
2. Select the entry in the list of the **Entries** tab or by
   Click in the preview and modify its form. 
3. Click on **Apply** and save the page. The date
   after "Status:" is set to the day of the change. 

Click **Cancel** to discard all changes since the last time you opened the
Plan Editors. 

## Download the plan as an Excel spreadsheet (as a reader)

1. Filter and zoom the plan so that you can see what you need. 
2. Click **Export** in the toolbar. On narrow
   screens, the button is in the menu **More**. 
3. Choose the scope: 
   - **Current View** — only the entries in the visible section that
     meet all active filters; if the search is active, only the hits. 
   - **Full plan** — all entries, without filters and sections. 

   Behind each election is how many entries it contains. 
4. Click on **Download Excel**. The file is named like the
   Heading of the plan with today's date, without heading
   'Projektplan_JJJJ-MM-TT.xlsx'. 

The file contains the sheet **Planning** with one line per entry (level, 
Type, Title, Category, Start, End, Series, Preliminary, Predecessor, 
description) and the sheet **Info** with title, status, export date, scope and
the active filters. 

## When something doesn't work

1. **The widget doesn't show anything on the page.** The plan doesn't have one yet.
   entry. Open Settings and set at least one
   milestone, time period, or deadline. 
2. **The plan editor does not open.** Under **Plan** there is only one
   Text box. Close and reopen the settings. Change
   Do not change the contents of the text field by hand — it is the technical
   Rough version of the plan. 
3. **At the top of the plan editor, it says that entries could not be read.** 
   See the FAQ for this report. 
4. **Readers can't find the "Export" button.** Check if
   **Offer Excel Export** is turned on.
