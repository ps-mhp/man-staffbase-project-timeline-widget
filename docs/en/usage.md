# Step by Step

## Creating the Plan

1. Place the **Project Plan** widget on the page, preferably in a
   wide column: A timeline needs width. In a
   narrow column, it remains usable but displays less information at a time.
2. Open the widget’s settings. The plan editor opens
   automatically in full-screen mode; it also covers the Studio toolbar.
3. A blank plan offers two options: **Start from Scratch** creates a layer
   named “Layer 1”; if you’d rather start with a ready-made template, follow the
   section “Start with a Template.”
4. In the header bar of the Plan Editor, under **Heading**,
   optionally enter a title for the plan. It appears above the plan and gives the
   Excel file its name.
5. Create the levels in the **Levels** tab—see “Managing Levels.”
6. Create the categories with their colors in the **Categories** tab—
   see “Managing Categories.”
7. In the **Entries** tab, create the milestones, time periods, and due dates
   — see the following sections.
8. Click **Apply** in the upper-right corner.
9. In the dialog box, check the **Show Today Line** and
   **Offer Excel Export** checkboxes; both are selected by default.
10. Save the page and review the result in the preview.

## Start with a Template

1. Open the settings for a widget whose plan is still empty.
2. In the plan editor, click **Start with a Template**. The editor displays
   the templates as cards, each with a preview image, description, and what
   they include:
   - **Product Roadmap** — multiple years and product lines, modeled after
     the “Sales Truck Launch” plan: three levels, seven categories, and every
     type of entry.
   - **Date Postponement** — a postponed date spanning a few months:
     old and new dates as reference dates, with one level per affected function.
3. Click on the appropriate card. The editor populates with the template;
   any heading you’ve already entered remains. **Back** takes you back to the two options
   without making any changes.
4. Customize the heading, levels, categories, and entries to fit your project
   or delete what you don’t need.
5. Click **Apply** in the top-right corner and save the page.

## Setting Up the Plan Editor

- **Collapse Preview:** Clicking **Preview** collapses the timeline
  and makes room for the tabs below it. When expanded, it returns to the
  last selected height.
- **Resize:** The divider between the preview and the tabs changes the
  height of the preview (at least high enough that the timeline remains visible),
  while the one between the entry list and the form changes the width of the list. Drag it with the mouse or place the focus on it and
  use the arrow keys (hold Shift for larger increments). A
  double-click restores the original size. The browser remembers
  the sizes for the next time you open the page.
- The list, form, layers, and categories each scroll independently; the header bar,
  tabs, and the buttons above each area remain stationary.

## The Entry List

- Above the list is **Browse Entries**; below it is a toggle
  for the type: **Milestones**, **Time Periods**, or **Dates**, each with
  its count. The list shows only entries of that type.
- The **+** button to the right of the toggle creates an entry of the
  selected type.
- A small icon in the color of its category appears before each title—this
  helps you locate an entry from the timeline in the list.
- The search applies only to the selected type; the numbers in the toggle
  then show how many results there are for each type.
- If you select an entry of a different type in the preview, the
  toggle changes accordingly.
- To delete an entry, hover your mouse over a row and click the
  trash can on the right (it’s always visible on touch devices). A small
  prompt will also indicate how many entries depend on the one being deleted; confirm
  by clicking **Delete**.

## The Entry Form

To the right of the list is the form for the selected entry. At the top are
its title and the **Duplicate** and **Delete** buttons; below them are five
tabs:

- **General** — Type, Title, Description
- **Classification** — Level, Category, Series
- **Date** — Date or Start and End; for time periods, an arrow at the end,
  Tentative
- **Dependencies** — the predecessors; the number after it indicates how many
  are selected. Key dates do not have this tab.
- **Content** — the Staffbase page or news post that opens when you click
  on the entry

The selected tab remains open when you switch to another entry
— if you’re managing the dates for multiple entries, stay on the **Date** tab. If a
tab contains an invalid entry, it displays a red dot.

## Managing Levels

1. In the Plan Editor, open the **Levels** tab.
2. To create a level, click **New Level** and enter
   its name. You can also do this directly in an entry’s form: under
   **Classification**, in the **Level** field, select the option **New Level …**, enter the
   name, and click **Create**—the new level is then immediately
   assigned to the entry.
3. To rename a level, change its name directly in the list.
   Next to each name is the number of entries the level contains. Each name
   may only appear once (case-insensitive).
4. To change the order, use the arrows to move the level
   up or down. The order here is the order on the
   page and in the Excel export.
5. To delete a level, click **Delete**. If it still contains
   entries, the editor will ask whether these should be moved to another level
  — select the destination under **Target Level**—or whether they should be deleted
  along with the level. Confirm with **Delete** or cancel with **Cancel**
  .

## Managing Categories

1. In the Plan Editor, open the **Categories** tab.
2. To create a category, click **New Category** and
   enter its name—or, in the entry form
   select the option **New Category …** in the **Category** field under **Classification**;
   there, specify the name, color, and shape.
3. Click the color swatch next to the name. A palette of twelve colors will appear;
   select one of them or enter a custom color under **Hex Value**,
   for example, `#E40045`. Press Esc or click next to the field to close the
   selection.
4. Click the shape button next to it and select the shape in which the
   milestones for this category will appear: diamond, triangle, downward-pointing triangle, square, circle, hexagon, star, or cross. The arrow buttons
   cycle through the shapes. A new category is assigned the first shape that
   has not yet been assigned to another category.
5. To change the order of the legend, move the category
   up or down using the arrows.
6. To delete a category, click **Delete**. Your entries
   will be retained and marked as “uncategorized” (gray); a prompt will indicate
   how many entries are affected.

## Creating a Milestone

1. In the Plan Editor, open the **Entries** tab.
2. Select **Milestones** above the list and click **+**. The
   new entry is named “New Milestone,” appears in the center of the preview
   and on the first level; its form appears on the right in the
   **General** tab, with the title field highlighted.
3. Enter the **Title** and, optionally, a **Description**. The
   description appears in the details; line breaks are preserved.
4. Under **Classification**, select the **Level** and the **Category** —
   or “No Category.”
5. Under **Due Date**, enter the **Date**.
6. The milestone’s shape and color are determined by its category; without
   a category, it appears as a gray diamond. Under **Classification**, there is a
   note indicating the shape it currently has.
7. Select **Tentative** if the date has not yet been set.
8. Click **Apply** in the upper-right corner once all entries are complete
  .

## Create a Time Period

1. In the **Entries** tab, select **Time Periods** above the list and click
   **+**. The new entry is named “New Time Period.”
2. Under **General**, enter the **Title** and, optionally, a
   **Description**; under **Classification**, enter the **Level** and **Category**.
3. Under **Date**, enter the **Start** and **End** dates. Both dates
   are part of the time period.
4. Check **Arrow at End** if the time period extends beyond the end date
  .
5. Select **Tentative** if the start or end date has not yet been determined.

A milestone can be converted to a time period at any time under **Type**,
and vice versa.

## Create a Deadline

1. In the **Entries** tab, select **Deadlines** above the list and click
   **+**.
2. Enter the **Title**, an optional **Description**, **Category**, and
   **Date**. There is no level here: A deadline applies to the
   entire plan and extends across all levels.

If a milestone or time period is set to a deadline under **Type**, its
level is removed.

## Group Entries into a Series

1. In the **Entries** tab, select the first entry in the series and
   open **Classification**.
2. Click in the **Series** field. This displays the series that already exist
   this level, each with the number of entries it contains. Type
   a new name, for example, “TG Assist MY26,” and select
   **“Create ‘TG Assist MY26’ as a new series”** (or press Enter).
3. Select the next entry on the same level and, under
   **Series**, select the series you just created from the list.
4. Repeat step 3 for all entries in the series. Selecting **No Series** at the
   very top of the list removes an entry; Esc restores the
   previous value.

Series apply only within a single level. Case does not
matter when searching, but hyphens and accents do: “TG Assist
MY26” and “TG-Assist MY26” are two different series.

## Setting a Dependency

1. In the **Entries** tab, select the entry that depends on another
   entry (the successor), and open **Dependencies**.
2. Under **Depends on**, search for and select the predecessor. Multiple
   predecessors are possible.
3. On the page, a dashed line with an arrow now connects the
   predecessor to the successor.

Dependencies exist only between milestones and time periods, not for
key dates. If an entry is deleted, it also disappears from all
dependencies.

## Linking a Page or a News Post

For each entry, you can link a Staffbase page or a news post—
such as the page with all the information about a software update. The plan remains the
overview; the details are where they’re maintained anyway.

1. Select the entry in the **Entries** tab and open the
   **Content** tab.
2. Under **Link**, select **Page** or **News Article**.
3. For a page, select it under **Page**. For a post,
   first select the **Channel**, then the **Post**. Drafts are marked with
   “(Draft)”; they can be linked, but readers
   won’t see them until they’re published.
4. **Open in a new tab** shows what’s linked.

If the page or post doesn’t exist yet, create it right here:

1. Click **New Page …** below the selection—or, for a
   post, after you’ve selected the **Channel**, click **New Post …**.
2. The Staffbase Editor opens above the schedule editor. Create the page
   there (**Create**) or save the post as a draft.
3. As soon as Staffbase has saved it, the content is linked to the entry;
   “Linked: …” will then appear at the top. You can continue writing in the Staffbase Editor.
   Clicking **Done** closes it.

If you close it with **Cancel** or Esc before anything is linked, the
editor will ask: If it has found exactly one new page or one new
post from you in the meantime, it will offer to link them; otherwise, it will ask
if you really want to cancel the creation—anything in the Staffbase Editor that
hasn’t been saved yet will be lost.

Below the link are the **Attachments**: files and images from the
Staffbase media library, up to ten per entry.

1. In the **Content** tab, click **Add File or Image…** and
   select a file from the media library—or upload a
   new one there.
2. If desired, enter a **label**; otherwise, the
   filename will appear there.
3. Use **↑** and **↓** to change the order; **×** removes the attachment.

Attachments remain after logging out: Readers open them with their own
permissions, just like any file from the media library.

On the page, the caption of a linked entry is underlined.
Clicking it opens the page or post in a window above the
map, instead of the details; **Open in a new tab** is always displayed at the top there, with the
attachments listed next to it. For an entry without linked content, the
details show its attachments. Use
**Link: None** to remove the link.

## Duplicating and Deleting Entries

1. Select the entry in the **Entries** tab.
2. **Duplicate** (top right of the form) creates a copy that you
   can then customize.
3. **Delete** (next to it) prompts you for confirmation and then removes the entry and all
   dependencies that reference it. The same confirmation prompt appears next to the
   trash can in the list. Afterward, the next entry in the list is selected.

## Setting the Start View

Without a start view, the widget displays the entire plan when it loads. If you want
it to show a specific section instead—such as the next two years—follow these steps:

1. Zoom and pan the **Preview** in the plan editor until the
   desired section is visible.
2. Click **Set this section as the default view**. This is saved
   on a monthly basis.
3. To show the entire plan again, click **Remove Start View**.
  .
4. Click **Apply**, save, and check the preview on the page.

Readers can zoom in further from the starting view at any time or use
**Show All** to view the entire map.

## Making Changes Later

1. Open the widget’s settings again. The Map Editor displays the
   saved map.
2. Select the entry from the list on the **Entries** tab or by
   clicking in the preview, and edit its form. Clicking in
   the preview switches to the **Entries** tab and brings the
   entry in the list into view.
3. Click **Apply** in the upper-right corner and save the page.
   The date after “Status:” is set to the date of the change.

As long as changes have not yet been saved, the header bar will display
“Unsaved changes.” Click **Cancel** to discard all changes
made since the last time you opened the plan editor; the editor will ask for confirmation first.

## Downloading the Plan as an Excel Spreadsheet (as a reader)

1. Filter and zoom the plan so that you can see what you need.
2. Click **Export** in the toolbar. On narrow
   screens, the button is located in the **More** menu.
3. Select the scope:
   - **Current View** — only the entries in the visible section that
     meet all active filters; if a search is active, only the results.
   - **Entire Plan** — all entries, without filters or section selection.

   The number of entries included is shown next to each option.
4. Click **Download to Excel**. The file is named after the
   plan’s heading with today’s date, without the heading:
   `Project_Plan_YYYY-MM-DD.xlsx`.

The file contains the **Planning** sheet with one row per entry (Level,
Type, Title, Category, Start, End, Series, Tentative, Predecessor,
Description) and the **Info** sheet with Title, Status, Export Date, Scope, and
the active filters.

## If something isn’t working

1. **The widget isn’t displaying anything on the page.** The plan doesn’t have any
   entries yet. Open the settings and create at least one
   milestone, time period, or due date.
2. **The plan editor won’t open.** Under **Plan**, you’ll see only a
   text field. Close the settings and open them again. Do not
   manually change the content of the text field—it is the technical
   draft of the plan.
3. **At the top of the Plan Editor, it says that entries could not be read.**
   See the FAQ for this message.
4. **Readers cannot find the “Export” button.** Check to see if
   **Offer Excel Export** is enabled.
